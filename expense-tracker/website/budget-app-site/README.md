# Сайт застосунку

Це окремий статичний сайт для презентації застосунку. Він не залежить від Vite, React або backend.

## Перегляд

Відкрийте `index.html` у браузері.
На Windows також можна запустити `preview.bat`.

## Структура

- `index.html` — сторінка сайту.
- `styles.css` — усі стилі.
- `script.js` — плавна навігація та кнопка повернення нагору.
- `assets/hero.png` — локальний візуальний ассет.
- `preview.bat` — швидке відкриття сайту в браузері на Windows.
